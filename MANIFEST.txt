LOCKED REPAIRS

1. CURRENT / ACTIVE STATE
Foods, treats, chews, supplements, medication foods, and medications now support explicit Current state.
Multiple current foods and multiple current medications are allowed simultaneously.
Sitter Mode reads all explicitly current food items and current medications.

Existing-data migration:
- newest existing feeding item in each category starts Current
- older same-category feeding items start Previous
- ongoing/not-yet-ended medications start Current
The user can then edit any item and change Current explicitly.

2. SITTER REOPEN / IPHONE SUSPEND
The previous implementation depended on lifecycle events that iOS does not always deliver when freezing/restoring a standalone PWA.
This build adds:
- pageshow check
- visibility check
- focus check
- app-shell check
- timer-gap heartbeat that detects a resumed frozen PWA
Active sitter mode should reassert the caretaker alert until explicitly ended.

3. ONE-TIME SETUP LINK
Normal setup is still:
family setup link -> type name/initials -> connected.
The code supplied by the setup URL is stored in:
- localStorage
- same-origin secure cookie
This improves handoff between Safari and the standalone iPhone PWA.
Manual code entry is hidden under Use connection code instead and remains recovery-only.

IMPORTANT:
A completely new device cannot connect with zero provisioning unless the private family write credential is embedded in public source or the backend is changed to support a pairing service.
This build does NOT expose that credential in public source.

4. PREVIOUS-ITEM DRAWERS
Generated Care history drawers now use ordinary button-driven expand/collapse controls instead of repeated native <details> elements.

5. CURRENT VISUAL MARKER
Current food items and current medications receive:
- subtle green left-edge marker
- Current badge

6. CAUTIONS IN SITTER MODE
All cautions still present in the active Care array are shown in Sitter Mode.
Removing a caution archives its history as before.

7. IPHONE MODAL REPAINT
Critical sitter/setup overlays no longer use backdrop blur.
Modal close paths release body scroll state and request a lightweight repaint.

8. FOCUS RAPID TAPS
Focus buttons retain current behavior and use touch-action: manipulation to reduce unwanted double-tap zoom.
